# Modèle de support (proposition)

- Support standard en jours ouvrés, par ticket (e-mail vers un outil de ticket à choisir).
- Canal urgent (téléphone/messagerie) réservé aux commandes ou paiements bloqués.
- Permanence critique pendant les principaux services (pilote : porteur du projet).
- Monitoring automatisé continu avec alertes : taux d'échec de paiement, commandes payées non injectées,
  délais de traitement, saturation des créneaux, erreurs d'intégration, file bloquée.
- Accès support aux données d'un tenant : `support_access_grant` temporaire (≤ 2 h), motif obligatoire,
  audité, visible par le propriétaire.
- Tableau de santé par restaurant sans donnée sensible.
- Indicateurs : tickets pour 100 commandes (objectif < 2 après apprentissage), temps de support mensuel
  par restaurant (entre dans le modèle de coûts).
